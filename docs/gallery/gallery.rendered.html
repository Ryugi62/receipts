How it works — all in the browser

1 · Splitsentences → atomic claims; “she” → the topic
→
2 · RetrieveWikipedia search per claim; prose only
→
3 · Rankword pre-filter (40) → MiniLM embeddings (top 5)
→
4 · InferDeBERTa NLI: backs / contradicts / neutral
→
5 · Gateclose in meaning + shared word + same subject — or no verdict
src/domain — claims · gate · verdict (pure)
src/application — checkAnswer + ports
src/adapters — Wikipedia · transformers.js
web/ · scripts/ — UI · evaluation · captures
